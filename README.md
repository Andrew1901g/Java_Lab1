# Java_Lab1

Первая лабораторная работа по Java.

В репозитории находятся исходные файлы Java, задание и отчёт.

## Запуск

Требуется JDK 10 или новее.

```sh
javac -encoding UTF-8 *.java
java nom11
```

Вместо `nom11` можно указать имя другого класса. Пример `nom3` намеренно демонстрирует `NullPointerException` при распаковке `null`.
